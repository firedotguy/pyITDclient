# Рейт лимиты
У ИТД есть 4 вида рейт лимитов:

## Для каждого эндпоинта
У каждого эндпоинта есть свой лимит запросов в минуту (можно посмотреть в заголовке `x-ratelimit-limit`). Оставшееся количество запросов можно посмотреть в заголовке `x-ratelimit-remaining`. 1 токен заполняется за `60 / limit` сек (за минуту восстановятся все токены). При достижении лимита в ответе будет `{'error': 'Too Many Requests'}`. Лимит распространяется на все запросы с одного IP.

!!! note "glossary"
    Токен - стоимость одного запроса. При новом запросе сниамется 1 токен.

## Для действий (минутный и часовой)
У каждого действия (лайк, подписка, комментарий итд) а также поиска есть отдельные лимиты (отличатся от первого, хотя они тоже на них есть) запросов в минуту и в час. При достиежении лимита в ответе будет `{'error': {'code': 'RATE_LIMIT_EXCEEDED', 'retry_after': 59, 'message': 'Слишком много лайков. Повторите позже.'}}`. `retry_after` вычисляется из даты первого запроса за последние `60 сек` (или `мин` если лимит часовой) минус дата последнего запроса. Лимит распространяется на все запросы с одного аккаунта.

| Действие                        | В минуту | В час |
|---------------------------------|----------|-------|
| Лайки                           | 30       | 200   |
| Создание комментариев и ответов | 5        | 75    |
| Подписки                        | 5        | 20    | 
| Репосты                         | 5        | 25    |
| Создание постов                 | 5        | 25    |

## По IP
Если сделать более 100 запросов за минуту (примерное значение, в реальности может быть другое), ИТД будет недоступен с вашего IP на несколько часов (как будто он не работает).
