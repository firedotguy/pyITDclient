Пользователь

Аттрибуты

id UUID

ID пользователя.

username str

Username.

display_name str aliasdisplayName

Отображаемое имя пользователя.

avatar str

Эмоджи-клан (аватар) пользователя.

verified bool

Верифицирован ли пользователь.

pin Pin

Установленный пин пользователя. None, если пользователь не установил пин.

banner str

Ссылка на баннер пользователя. None, если баннер не установлен.

bio str

Био пользователя. None, если он не задал описание или аккаунт приватный (см. is_private).

Note

Если пользователь поставит в био пробел (" "), то значение будет "" (хотя если бы он оставил поле пустое, то значение было бы None)

followers list[User] property

Статичный список подписчиков. Максимальная длина - 20, отсортирован по дате подписки (первые 20 подписавшихся). Если еще не загружен, автоматически подгрузится. Пустой список, если пользователь заблокирован или аккаунт приватный (см. is_private).

following list[User] property

Статичный список подписок (на кого подписан пользователь). Максимальная длина - 20, отсортирован по дате подписки (первые 20 подписок). Если еще не загружен, автоматически подгрузится. Пустой список, если пользователь заблокирован или аккаунт приватный (см. is_private).

is_following bool aliasisFollowing

Подписаны ли вы на пользователя. Автоматически изменяется при follow()/unfollow().

is_followed_by bool aliasisFollowedBy

Подписаны ли пользователь на вас.

is_blocking bool aliasisBlocking

Заблокировали ли вы пользователя. Автоматически изменяется при user.block()/user.unblock().

is_blocked_by bool aliasisBlockedBy

Заблокировал ли вас пользователь.

Info

Если is_blocking или is_blocked_by == True, то большинство данных (такие как bio, followers, posts, created_at и тд) будут None.

blocked_at datetime aliasblockedAt

Дата блокировки. Известна только когда is_blocking == True.

followers_count int aliasfollowersCount

Количество подписчиков (отличается от len([followers](#followers-list-user)), так как самих пользователей показывает только первые 20шт). None, если аккаунт приватный (см. is_private).

following_count int aliasfollowingCount

Количество подписок (отличается от len([following](#following-list-user)), так как самих пользователей показывает только первые 20шт). None, если аккаунт приватный (см. is_private).

posts_count int aliaspostsCount

Количество постов. None, если аккаунт приватный (см. is_private).

wall_access AccessType aliaswallAccess

Доступ к созданию постов на стене пользователя. None, если пользователь заблокирован.

  • AccessType.NOBODY - никто
  • AccessType.MUTUAL - взаимные подписки (вы подписаны на пользователя и он подписан на вас)
  • AccessType.FOLLOWERS - подписчики
  • AccessType.EVERYONE - все

likes_visibility AccessType aliaslikesVisibility

Доступ к лайкнутым постам пользователя. None, если пользователь заблокирован.

is_private bool aliasisPrivate

Приватный ли аккаунт пользователя. None, если вы подписаны на пользователя (при подписке ограничения приватности пропадают).

Info

Если is_private == True, то большинство данных (такие как bio, followers, posts, created_at и тд) будут None. Для получения реальных значений нужно подписаться на пользователя.

is_subscribed bool aliashasNuksta

Есть ли у пользователя подписка ИТД НУСКТА.

last_seen | dict | datetime aliaslastSeen

Дата последней активности. Может быть как и точным временем datetime, так и относительным dict (недавно, несколько минут назад и тд). Пока точно неизвестны все возможные значения. None, если пользователь заблокирован, приватный аккаунт или показ скрыт в настройках приватности пользователя.
Примерная структура словаря: 

{
    "unit":
        "recently" | /*(1)*/
        "minutes" | /*(2)*/
        "hours" | /*(3)*/
        "this_week" | /*(4)*/
        "this_month" | /*(5)*/
        "long_ago" | /*(6)*/,
    "value": null | int
}

  1. Недавно
  2. {value} минут назад
  3. {value} часов назад
  4. На этой неделе
  5. В этом месяце
  6. Давно (примерно 3+ месяцев)

online bool

Находится ли пользователь в онлайне.

pinned_post_id UUID aliaspinnedPostId

ID закрепленного поста. None, если у пользователя нет закрепа.

created_at datetime aliascreatedAt

Дата создания аккаунта. None, если пользователь заблокирован или у него приватный аккаунт.

posts UserPosts property basesITDList

Список постов. (см. UserPosts)

liked_posts LikedPosts property basesITDList

Список лайкнутых постов. (см. LikedPosts)

Получить пользователя

user = User('itd_sdk')
Принимает как ID, так и username.

Получить пользователя по ID

user = User.by_id('587167e9-25ad-4948-afc0-2ee5bc9097ea')

Получить пользователя по username

user = User.by_username('itd_sdk')
или 
user = User.by_u('itd_sdk')

Abstract

если передаете ID в User(xxx), он обязательно должно быть в типе UUID. Если вам нужно передать ID как строку, используйте User.by_id(xxx). User.by_u(xxx) принимает только str (без лишних проверок на UUID).

Получить текущего пользователя

user = User.me()
или 
user = Me()
см. документацию для Me()

Параметры

username_or_id | str | UUID Required

Username или ID пользователя.

Note

Для проверки на существование (NotFoundError) вызовите user.refresh() или любой аттрибут (если не включен config.auto_load)

Пожаловаться

report = user.report(
    reason=ReportReason.SPAM,
    description='описание'
)
Пожаловаться на пользователя.

Параметры

reason ReportReason Required

Причина жалобы.

  • ReportReason.SPAM: Спам или нежелательный контент
  • ReportReason.VIOLENCE: Насилие или опасные действия
  • ReportReason.HATE: Ненависть или травля
  • ReportReason.ADULT: Контент для взрослых (18+)
  • ReportReason.FRAUD: Дезинформация или обман
  • ReportReason.OTHER: Другое

description str

Описание жалобы.

Ошибки

  • NotFoundError - пользователь не найден.
  • AlreadyReportedError - вы уже оставляли жалобу на этого пользователя.
  • ValidationError - ошибка валидации (слишком длинное описание).

Подписаться

followers_count = user.follow()
Подписаться на пользователя.

Ошибки

  • NotFoundError - пользователь не найден.
  • AlreadyFollowingError - вы уже подписаны на этого пользователя.
  • TooLargeError - слишком длинный юзернейм.
  • CantFollowYouself - нельзя подписываться на самого себя.
  • UserBlockedError - пользователь заблокирован (или вы заблокировали его).
  • TargetUserBannedError - пользователь забанен.

Отписаться

followers_count = user.unfollow()
Отписаться от пользователя.

Ошибки

  • NotFoundError - пользователь не найден.
  • TooLargeError - слишком длинный юзернейм.
  • TargetUserBannedError - пользователь забанен.

Заблокировать

user.block()

Warning

После блока подписка слетает: если вы были подписаны на пользователя, то автоматически отписываетесь, и наоборот, если пользователь был подписан на вас подписка пропадает. Даже после unblock() подписка не восстановится (нужно подписываться заново вручную).

Ошибки

  • NotFoundError - пользователь не найден.
  • TooLargeError - слишком длинный юзернейм.
  • AlreadyBlockedError - пользователь итак заблокирован.
  • CantBlockYourselfError - нельзя заблокировать самого себя.
  • TargetUserBannedError - пользователь забанен.

Разблокировать

user.unblock()

Ошибки

  • NotFoundError - пользователь не найден.
  • TooLargeError - слишком длинный юзернейм.
  • NotBlockedError - пользователь итак не заблокирован.
  • TargetUserBannedError - пользователь забанен.

Пост на стене

user.post(
    content='содержание',
    spans=[],
    attachments=[],
    poll=NewPoll(
        question='тест',
        options=['1', '2', '3', '4', '5'],
        multiple=True
    )
)

Параметры

content str One of required

Содержание поста.

spans list[Span]

Стилизация (жирный, курсив, подчеркивание итд). Автоматически заполняется, если установлен parse_mode. У ручного заполнения приоритет большем, чем у дефолтного (если у вас стоит parse_mode в конфиге, и вы напишите свой spans, применится ваш вариант).

wall_recipient | UUID | User

Получатель поста (для постов на стене). Может быть объектом пользователя или UUID.
Для поста на стене также можно использовать user.post().

attachments | || | list[UUID | File] | File | UUID One of required

Вложения. Может быть списком, объектом файла или UUID.

poll NewPoll One of required

Опросник.

Ошибки

  • NotFoundError - получатель поста не найден.
  • ForbiddenError - некоторые вложения не принадлежат клиенту или не существуют. Вложения должны быть загружены одним и тем же клиентом через upload_file.
  • ValidationError - ошибка валидации, скорее всего из-за слишком большого количества символов.
  • RequiresSubscriptionError - для публикации видео нужна верификация или НУКСТА.
  • BannedWordError - в посте содержатся запрещенные слова.

Обновить

user.refresh()

Ошибки

  • NotFoundError (User) - пользователь не найден.
  • TooLargeError - слишком дилнный юзернейм.
  • NotFoundError (Profile) - профиль не найден (пользователь только привязал почту, но еще не добавил эмоджи клан и имя)
  • TargetUserBannedError - пользователь забанен.

Выполнить действия для постов на стену

is_succeed = user.complete_actions_for_wall_access()

Выполнить действия для просмотра лайков

is_succeed = user.complete_actions_for_likes_visibility()

Аттрибуты

Username.

Эмоджи-клан (аватар) пользователя.

Установленный пин пользователя. None, если вы не установили пин.

Ссылка на баннер пользователя. None, если баннер не установлен.

Био пользователя. None, если био пустое.

Количество подписчиков.

Количество подписок.

Количество постов.

Доступ к созданию постов на вашей стене.

Доступ к лайкнутым постам.

Приватный ли у вас аккаунт.

Верифицирован ли норме телефона (подтвережден через телеграм).

Данные о подписке. (см. Subscription)

Дата создания аккаунта.

Список подписчиков.

Список подписок.

blocked Blocked property basesITDList

Список заблокированных пользователей.

Список постов. (см. UserPosts)

Список лайкнутых постов. (см. LikedPosts)

pins list[Pin] property

Список пинов. (см. Pin)

profile Profile property

Профиль пользователя (чем-то похож на сам Me, но берется отдельным зарпосом /api/profile). (см. Profile)

Обновить профиль

from itd.enums import UNSET

profile = me.update(
    bio='био',
    display_name='имя',
    username='username',
    banner_id=UNSET
)

Обновить из текущих аттрибутов

me.username = 'username2'
me.bio = 'другое био'
me.update_from_fields()

Параметры

username str

Новый юзернейм.

display_name str

Новое имя.

bio str

Биография (о себе).

banner_id | UNSETUUID | Unset

ID баннера (должен быть загружен через upload_file).

Tip

Для удаления баннера используйте UNSET:

from itd.enums import UNSET

me.update(banner_id=UNSET)

Ошибки

  • ValidationError - ошибка валидации (например слишком длинное имя).
  • RequiresVerificationError - требуется верификация для загрузки GIF-баннера.
  • UsernameTakenError - username уже занят.

Обновить настройки приватности

from itd.models.user import UserPrivacyData
from itd.enums import AccessType

privacy = me.update_privacy(
    is_private=False,
    wall_access=AccessType.EVERYONE,
    likes_visibility=AccessType.FOLLOWERS,
    show_last_seen=True
)

Параметры

is_private bool

Приватный профиль. Посты не будут попадать в ленту, профиль будет виден только для подписчиков.

wall_access AccessType

Доступ к стене.

likes_visibility AccessType

Доступ к лайкнутым постам.

show_last_seen bool

Показывать дату последнего захода.

Ошибки

  • ValidationError (скорее всего ошибка в sdk)

Удалить аккаунт

me.delete()

Danger

У вас будет 30 дней на восстановление аккаунта (см. восстановление аккунта ниже). После этого аккаунт безвозратно удалится.

Интересный факт

Сам аккаунт не удалится из базы, просто can_restore заменится на False.

Ошибки

  • AlreadyDeletedError - аккаунт уже удален.

Восстановить аккаунт

me.restore()

Ошибки

  • NotDeletedError: Аккаунт итак не удален.

Note

Здесь также должна быть ошибка, что уже слишком поздно, но к сожалению у меня нет дополнительного аккаунта для удаления, чтобы посмотреть как она называется 🫤.

Установить пин

me.set_pin(me.pins[0])

Параметры

pin | str | Pin

Объект пина или слаг. Если None - устанавливается первый из списка.

Ошибки

  • ValueError - список пинов пустой (если pin is None).
  • PinNotOwnedError - пин не принадлежит вам.

Снять пин

me.remove_pin()
